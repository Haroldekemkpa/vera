# Weather Integration Setup

## Required OpenWeather configuration

- Create an OpenWeather account.
- Generate an API key.
- Ensure the current weather and 5 day forecast APIs are enabled for the key.

## Required environment variables

- `OPENWEATHER_API_KEY`

## Supported query settings

- `units`: `standard`, `metric`, or `imperial`
- `lang`: OpenWeather language code, for example `en`
