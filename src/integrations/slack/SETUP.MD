# Slack Integration Setup

## Required Slack configuration

- Create a Slack app.
- Install it to the workspace.
- Copy the bot user OAuth token.
- Invite the app to private channels before reading or posting in them.

## Required environment variables

- `SLACK_BOT_TOKEN`

## Required bot scopes

- `channels:read`
- `channels:history`
- `chat:write`
- `groups:read`
- `groups:history`
