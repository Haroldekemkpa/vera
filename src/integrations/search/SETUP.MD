# Search Integration Setup

## Required Tavily configuration

- Create a Tavily account.
- Generate an API key.

## Required environment variables

- `TAVILY_API_KEY`

## Supported query settings

- `searchDepth`: `basic` or `advanced`
- `topic`: `general` or `news`
- `maxResults`: 1 to 20
- `includeAnswer`, `includeRawContent`, and `includeImages`
